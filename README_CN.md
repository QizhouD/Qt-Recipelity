# 智能食谱管理系统

一个功能强大的食谱管理软件，支持从网页导入食谱、智能搜索筛选和营养分析。

## 功能特点

### 基础功能

1. **食谱收集与管理**
   - 手动添加和编辑食谱
   - 从主流美食网站自动抓取食谱
   - 支持导入结构化食谱数据
   - 本地数据库存储，安全可靠

2. **智能搜索与筛选**
   - 基于关键词的全文搜索
   - 多维度筛选（标签、烹饪时间、难度、菜系等）
   - 快速定位所需食谱

3. **营养分析**
   - 自动计算食谱的营养成分
   - 可视化展示营养构成
   - 支持多种食材的营养数据

### 亮点功能

1. **网页食谱自动导入**
   - 支持从美食天下、下厨房、豆果美食等网站自动提取食谱信息
   - 智能解析网页结构，提取食材、步骤等关键信息

2. **食物图像分析**
   - 使用OpenCV进行食物图像分割
   - 识别食材种类和估算重量
   - 基于图像自动生成食谱

## 技术栈

- **前端框架**: Qt 6 (使用PyQt6)
- **后端语言**: Python 3.9+
- **数据库**: SQLite + SQLAlchemy
- **图像处理**: OpenCV
- **网络请求**: Requests + BeautifulSoup4
- **数据可视化**: Matplotlib

## 安装与运行

### 前提条件

- Python 3.9 或更高版本
- pip 包管理工具

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行应用

```bash
python main.py
```

## 使用指南

### 添加食谱

1. 点击菜单栏的"文件" -> "添加食谱"
2. 填写食谱信息，包括名称、描述、食材、步骤等
3. 点击"保存"按钮

### 从网页导入食谱

1. 点击菜单栏的"文件" -> "从URL导入食谱"
2. 输入食谱网页的URL
3. 等待解析完成后，确认或编辑食谱信息
4. 点击"保存"按钮

### 搜索与筛选食谱

1. 使用左侧筛选面板设置搜索条件
2. 输入关键词进行搜索
3. 勾选标签、设置时间范围和难度等筛选条件
4. 点击"重置筛选"恢复默认设置

### 营养分析

1. 选择一个食谱
2. 点击详情面板中的"分析营养成分"按钮
3. 等待分析完成，查看营养成分图表

### 从图片分析食材

1. 点击菜单栏的"文件" -> "从图片分析食材"
2. 选择一张食物图片
3. 等待分析完成，查看识别到的食材
4. 选择是否使用这些食材创建新食谱

## 数据说明

应用使用SQLite数据库存储所有数据，数据库文件位于 `data/recipes.db`。

主要数据模型包括：
- Recipe: 食谱基本信息
- Ingredient: 食材信息
- Step: 烹饪步骤
- Nutrition: 营养成分
- Tag: 标签
